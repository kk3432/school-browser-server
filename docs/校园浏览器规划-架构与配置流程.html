  • 一套服务端代码跑两个系统：Windows Server 上用 IIS 托管，将来迁 Linux 换成 systemd + Kestrel，业务代码零改动。
  • 安卓明文 HTTP 必须显式放行：Android 9 起系统默认禁止 http:// 明文，需在 network_security_config 中放行内网服务器地址，否则连不上。
  • 规模估算：约 100 台平板、5 分钟轮询一次 ≈ 每分钟 20 次请求，单台普通服务器即可承载，无需集群。
  • 访问控制：启动直达首页，白/黑名单在 WebViewClient 层逐条拦截，学生无法手输其他网址；UI 用开源库拼装（AgentWeb / SmartRefreshLayout / Material 组件）。
  • 首次启动强制联网：第一次进 APP 必须拉到配置，否则停在"连接服务器"页；管理员 6 位密码（MD5 本地比对）可改服务器地址或临时放开管控，重启 APP 即失效。
